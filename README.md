This repository contains my personal portfolio website, where I showcase my professional experience, technical skills, and selected projects.

I’m a Frontend Engineer with 4+ years of experience building web applications, real-time interfaces, and AI-powered products.

## Tech Stack

- React
- TypeScript
- JavaScript
- Vite
- SCSS
- HTML

- WebSocket
- REST APIs

## Features

- Responsive design across desktop, tablet, and mobile
- Light and dark theme
- Accessible navigation and interactive components
- Project details with modal views
- Resume download
- Responsive mobile navigation
- Reduced-motion support
- Performance-focused frontend implementation
